## OSINT Data Collection Using VirusTotal

### Phishing URL Analysis

For this task, I used VirusTotal to investigate a phishing URL as part of the Phishing Threat Intelligence Analysis project.

Analyzed URL:

https://login-outlook365.yzz.me/

The URL was found in the PhishTank phishing database, where it was classified as a valid phishing URL.

### VirusTotal Analysis

I submitted the URL to VirusTotal to collect information about the threat.

During the analysis, I checked:

- Security vendor detections
- URL reputation
- Domain information
- Related IP addresses
- Related URLs and domains
- Community information

VirusTotal helps CTI analysts collect information from multiple security sources and identify potentially malicious indicators.

### Conclusion

This analysis demonstrates how VirusTotal can be used in Cyber Threat Intelligence to investigate phishing indicators. The analyzed URL was reported by PhishTank as a valid phishing URL. By checking the URL in VirusTotal, we can collect additional information about its reputation, detections, infrastructure, and related indicators
